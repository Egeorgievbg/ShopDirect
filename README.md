# ShopDirect · Marketing Intelligence Lab

An interactive, reproducible academic marketing analytics project for ShopDirect campaign response targeting.

- **Study:** P3.1 — targeting personalized offers in an online store
- **Student:** Илияна Цанова · 252042
- **Data:** instructor-supplied `P3_1_campaign_response.csv` (not included in this public repository)
- **Methods:** logistic regression and random forest on the same stratified train/test split
- **Output:** an interactive research website and on-demand Python reproduction of the original analysis

> The historical response prediction is **not** a causal uplift model. Reproduced model results require the instructor's CSV.

## Development

Development is performed on feature branches. The default `main` branch is reserved for reviewed changes. The website, API and setup details are developed in `feat/shopdirect-live-lab`.

## Academic integrity and privacy

The original CSV is not committed or hosted publicly. The application processes uploaded data only for the requested calculation and does not intentionally persist it. Users must verify permission to process the dataset, and the instructor's instructions take precedence.
